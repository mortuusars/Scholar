# Changelog

## UNRELEASED
- Mod has been **changed** and **rewritten** in many places:
  - Scholar colored books have been **disabled** in favor of new coloring system.
    - They are still in the game for a short while and can be used in hand to convert them to a correct item.
  - Config has been **restructured**. Some settings were removed. Several settings have been added.


- Chiseled Bookshelf now has an in-world tooltip that shows what book is stored in the hovered slot.


- Font color of the Book Signing Screen 'Enter Book Title' and 'by <author>' text is now configurable.
- Font color of the book title text box now uses 'MainFontColor' config setting.
